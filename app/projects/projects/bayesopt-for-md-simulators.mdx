## The target state

The system is glycerol coarse-grained to three beads, one per C–OH unit, 30.698 u each,
125 molecules at glycerol's experimental density (1261 kg/m³, 298.15 K) in a fixed cubic
box. Nine parameters are free:

| parameter | units | search range | role |
|---|---|---|---|
| `epsilon` | kJ/mol | 1.0 – 8.0 | Lennard-Jones well depth |
| `sigma` | nm | 0.28 – 0.45 | bead diameter |
| `bond_length_nm` | nm | 0.20 – 0.40 | equilibrium bond length |
| `bond_k` | kJ/mol/nm² | 400 – 6000 | bond force constant |
| `angle_deg` | ° | 80 – 175 | equilibrium angle |
| `angle_k` | kJ/mol | 5 – 150 | angle force constant |
| `timestep_fs` | fs | 2 – 38 | integration timestep |
| `thermostat_tau_ps` | ps | 0.05 – 3.0 | thermostat coupling |
| `cutoff_nm` | nm | 0.80 – 1.28 | non-bonded cutoff |

The **target state** is a vector of seven measured properties, generated by simulating a
hidden reference parameter set. Recovering that state is the task:

| symbol | target value | property |
|---|---|---|
| $U^{*}$ | $-41.248\ \mathrm{kJ\,mol^{-1}}$ | potential energy per molecule |
| $P^{*}$ | $-38.24\ \mathrm{bar}$ | pressure at fixed density |
| $D^{*}$ | $1.5687\times10^{-5}\ \mathrm{cm^{2}\,s^{-1}}$ | self-diffusion coefficient |
| $\langle b \rangle^{*}$ | $0.29963\ \mathrm{nm}$ | mean bond length |
| $\sigma_{b}^{*}$ | $0.035965\ \mathrm{nm}$ | bond-length spread |
| $\langle \theta \rangle^{*}$ | $127.199^{\circ}$ | mean angle |
| $\sigma_{\theta}^{*}$ | $16.477^{\circ}$ | angle spread |

Each parameter has an observable that constrains it: the well depth tracks `U`, the
pressure at fixed density separates `sigma` from `epsilon`, the means give the equilibrium
bond and angle, and equipartition ties the two *spreads* to the two force constants.

The loss is a weighted relative error against that vector, plus an energy-drift penalty:

$$
\mathcal{L}(\boldsymbol{\theta}) \;=\;
\sum_{k} w_{k}\,\frac{\bigl| O_{k}(\boldsymbol{\theta}) - O_{k}^{*} \bigr|}{s_{k}}
\;+\;
w_{\mathrm{drift}} \, \min\!\left( \frac{\Delta E(\boldsymbol{\theta})}{0.5}, \, 1 \right)
$$

| $k$ | $w_k$ | $s_k$ |
|---|---|---|
| potential energy | 0.20 | $\lvert U^{*} \rvert$ |
| pressure | 0.15 | $500\ \mathrm{bar}$ — fixed scale, not relative |
| diffusion | 0.15 | $\lvert D^{*} \rvert$ |
| mean bond | 0.15 | $\lvert \langle b \rangle^{*} \rvert$ |
| bond spread | 0.10 | $\lvert \sigma_{b}^{*} \rvert$ |
| mean angle | 0.15 | $10^{\circ}$ — fixed scale, not relative |
| angle spread | 0.10 | $\lvert \sigma_{\theta}^{*} \rvert$ |
| energy drift | 0.15 | $0.5\ \mathrm{kJ\,mol^{-1}\,ps^{-1}}$, capped at 1 |

Pressure and the mean angle are normalised by fixed physical scales rather than by their
own values, because both have an arbitrary zero and a relative error would make them
nearly invisible to the loss.

Two numbers set the scale. Re-simulating the *true* parameters gives a loss of **0.0351**
— that is sampling noise, the floor, and nothing below it is a result. "Good enough" is
set at **0.12**.

## The Bayesian optimisation setup

Two configurations, both searching the same nine-dimensional box above.

**Single-surrogate.** One Gaussian Process over the scalar loss, via `scikit-optimize`:

```
Optimizer(
    dimensions       = [Real(lo, hi) for each of the 9 parameters],
    base_estimator   = "GP",              # Matérn kernel, fitted noise term
    acq_func         = "gp_hedge",        # portfolio over EI / PI / LCB,
                                          # re-weighted each iteration
    n_initial_points = 10,                # random, or an LLM-designed warm-up
)

# a crashed simulation returns no loss, so one is invented for the surrogate:
tell(x, unstable_penalty)                 # 0.7 ("tuned") or 10.0 ("untuned")
```

**Multi-output.** One GP per measured observable rather than one over the loss, with the
targets used exactly and the loss composed analytically:

Each observable $k$ gets its own Gaussian Process, $\mathrm{GP}_k(\boldsymbol{\theta})
\rightarrow \bigl( \mu_k, v_k^2 \bigr)$, where $v_k$ is the predictive standard deviation.
The loss and its variance are composed from those predictions rather than modelled
directly, reusing the weights $w_k$ and scales $s_k$ from the loss above:

$$
\hat{\mathcal{L}}(\boldsymbol{\theta}) = \sum_{k} w_{k}\,
\frac{\bigl| \mu_{k}(\boldsymbol{\theta}) - O_{k}^{*} \bigr|}{s_{k}}
\qquad
\mathrm{Var}(\boldsymbol{\theta}) = \sum_{k} \left( \frac{w_{k}\, v_{k}(\boldsymbol{\theta})}{s_{k}} \right)^{2}
$$

$$
a(\boldsymbol{\theta}) \;=\;
\underbrace{\hat{\mathcal{L}}(\boldsymbol{\theta}) - \kappa \sqrt{\mathrm{Var}(\boldsymbol{\theta})}}_{\text{lower confidence bound},\ \kappa = 1.6}
\;+\;
\underbrace{10^{3} \cdot \mathbf{1}\bigl[\, p_{\mathrm{feas}}(\boldsymbol{\theta}) < 0.35 \,\bigr]}_{\text{feasibility gate}}
$$

$$
\boldsymbol{\theta}_{\text{next}} = \arg\min_{\boldsymbol{\theta} \in \mathcal{C}} a(\boldsymbol{\theta}),
\qquad |\mathcal{C}| = 4000 \ \text{random candidates}
$$

Crashes train the separate feasibility model $p_{\mathrm{feas}}$; the observable GPs are
fitted only on the runs that produced observables.

Both configurations screen the two analytically knowable failure modes before spending a
simulation, which is what a practitioner configuring BO would encode:

$$
\text{minimum image:} \quad r_{\mathrm{cut}} > \tfrac{1}{2} L_{\mathrm{box}}
\;\;\Longrightarrow\;\; \text{reject}
$$

$$
\text{blow-up:} \quad \Delta t > \frac{\tau_{\mathrm{bond}}}{20},
\qquad \tau_{\mathrm{bond}} = 2\pi \sqrt{\frac{\mu}{k_{\mathrm{bond}}}}
\;\;\Longrightarrow\;\; \text{reject}
$$

## The LLM setup

No surrogate and no acquisition function. The model proposes every parameter set itself,
seeing the same target vector and the outcome of every previous run. One call per
simulation:

```text
SYSTEM
  You are fitting a coarse-grained force field for liquid glycerol by
  running simulations one at a time.

  <system description: 3-bead mapping, 125 molecules, 1261 kg/m3, 298 K,
   fixed cubic box, velocity Verlet, Berendsen thermostat>

  <the nine free parameters and their hard bounds>

  <the seven target observables, O* above, with units>

  <the loss: weighted relative error against those targets, plus a drift
   penalty; the noise floor of 0.0351 and why it cannot be beaten>

  <the failure modes: blow-up when the timestep is too large for the bond
   vibration; minimum image when the cutoff exceeds half the box>

  Every simulation costs real compute whether it succeeds or fails, so a
  wasted run is a wasted budget. Your job is to choose the next parameter
  set to simulate, using everything the previous runs have told you -- and,
  before any run has told you anything, whatever the target properties
  themselves imply about the parameters that would produce them.

USER  (regenerated every step)
  Results so far:

  run  1: epsilon=3.000 sigma=0.3350 timestep_fs=18.00
          thermostat_tau_ps=0.500 cutoff_nm=1.100   ->  loss 0.4213
  run  2: epsilon=2.400 sigma=0.3420 timestep_fs=26.00
          thermostat_tau_ps=0.700 cutoff_nm=1.200   ->  FAILED (blowup)
  ...
  Best loss so far: 0.1673

  Propose the next parameter set to simulate.

RESPONSE  (constrained by a JSON schema)
  { "epsilon": ..., "sigma": ..., ... , "reasoning": "..." }
```

What the prompt contains is the whole design of the experiment. It includes the target
observables — that is the fitting data, exactly what a practitioner parameterising a force
field has in front of them. It never includes the reference parameters.

Two things the model is *not* given, both visible in the transcript above. It never sees
what its own runs measured, only the scalar loss they scored: a distance, not a direction.
And the history lists five of the nine parameters — `bond_length_nm`, `bond_k`,
`angle_deg` and `angle_k` are proposed each step but never echoed back, so the four bonded
parameters carry no memory between runs.
